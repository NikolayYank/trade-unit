# INSTALL.md — установка Trade Unit на компьютер пользователя (для агента)

Это пошаговая инструкция для ИИ-агента (Codex, Claude Code и подобных), которому пользователь написал: «установи это».
Пользователь не будет ничего вводить в терминал, скачивать или настраивать. Всё делаешь ты. Спрашивай его только там, где
это прямо сказано ниже (например, нужен пароль администратора).

Репозиторий открытый: https://github.com/NikolayYank/trade-unit . Аккаунт GitHub не нужен ни тебе, ни пользователю.

## 0. Что тебе нужно от среды

- Запуск команд на компьютере пользователя (терминал) и доступ в интернет (скачать код и пакеты npm).
- Если твоя среда запрещает сеть или команды (в Codex это настройки песочницы и подтверждения), попроси пользователя
  разрешить их или подтвердить запросы по мере появления. Если разрешить нельзя, прямо скажи, что без этого установить не получится.

## 1. Осмотри компьютер (выполни сам и запомни результаты)

| Что проверить | macOS / Linux | Windows (PowerShell) |
|---|---|---|
| Система | `uname -s` | `$PSVersionTable.OS` |
| Node.js (нужен 20.19+ или 22.12+) | `node -v` | `node -v` |
| npm | `npm -v` | `npm -v` |
| git (не обязателен) | `git --version` | `git --version` |
| Порт 4317 свободен | `lsof -i :4317` (пусто = свободен) | `Get-NetTCPConnection -LocalPort 4317` |
| Место на диске (нужно ~500 МБ) | `df -h ~` | `Get-PSDrive C` |

## 2. Поставь недостающее

- **Node.js нет или старый.** Поставь актуальную LTS-версию.
  - macOS: `brew install node` (если есть Homebrew), иначе скачай установщик `.pkg` LTS с https://nodejs.org и установи.
  - Windows: `winget install OpenJS.NodeJS.LTS`, потом открой новый терминал (чтобы обновился PATH) и проверь `node -v`.
  - Linux: через менеджер пакетов (NodeSource) или `nvm install --lts`.
  - Если для установки нужен пароль администратора или подтверждение, попроси пользователя ввести/подтвердить это, больше ничего от него не требуется.
- **git** ставить не обязательно: код можно скачать архивом (шаг 3, способ Б).

## 3. Получи код

Папка назначения: `trade_unit` в домашней папке пользователя. Если такая папка уже есть, не перезаписывай её: если это этот же проект,
обнови его (`git pull`) и переходи к шагу 4, если нет, возьми другое имя.

- **Способ А (есть git):** `git clone https://github.com/NikolayYank/trade-unit.git trade_unit`
- **Способ Б (git нет):**
  - macOS / Linux: `curl -L -o trade_unit.zip https://github.com/NikolayYank/trade-unit/archive/refs/heads/main.zip && unzip trade_unit.zip && mv trade-unit-main trade_unit`
  - Windows: `Invoke-WebRequest https://github.com/NikolayYank/trade-unit/archive/refs/heads/main.zip -OutFile trade_unit.zip; Expand-Archive trade_unit.zip .; Rename-Item trade-unit-main trade_unit`

## 4. Установи зависимости и проверь

В папке `trade_unit`:

1. `npm ci` (если не получилось, `npm install`).
2. `npm test`: все тесты должны быть зелёными.
3. `npm run build`: без ошибок.

## 5. Запусти и открой

`npm start` собирает сайт и поднимает его на `http://localhost:4317`, при этом он занимает терминал. Поэтому запусти его в фоне:

- macOS / Linux: `nohup npm start > start.log 2>&1 &`
- Windows (PowerShell): `Start-Process -WindowStyle Hidden -FilePath npm.cmd -ArgumentList start`

Подожди 5–15 секунд и проверь, что сайт отвечает: `curl -s -o /dev/null -w "%{http_code}" http://localhost:4317` должно вернуть `200`.
Потом открой адрес в браузере пользователя: macOS `open http://localhost:4317`, Windows `start http://localhost:4317`, Linux `xdg-open http://localhost:4317`.

Адрес и порт менять нельзя: данные сайта хранятся в браузере и привязаны к адресу.

## 6. Сделай запуск без тебя

В папке есть готовые файлы запуска: `start.command` (macOS, Linux) и `start.bat` (Windows). Они сами ставят недостающее, собирают сайт и открывают браузер.
Создай для пользователя ярлык на рабочем столе:
- macOS: `ln -s "$HOME/trade_unit/start.command" "$HOME/Desktop/Trade Unit.command"`
- Windows: ярлык на `start.bat` на рабочем столе (через PowerShell `WScript.Shell` → `CreateShortcut`).
- Linux: ярлык `.desktop` с командой `bash ~/trade_unit/start.command` или просто скажи пользователю, как запускать.

## 7. Если что-то пошло не так

| Проблема | Что делать |
|---|---|
| Порт 4317 занят | Проверь, не наш ли это сайт: `curl -s http://localhost:4317` содержит «Trade Unit». Если да, просто открой его. Если порт занят чужой программой, чужие процессы не убивай: объясни пользователю и спроси, что делать. Порт менять нельзя. |
| Нет сети или пакеты не качаются | Проверь интернет и прокси, повтори. Если сеть запрещена твоей средой, попроси разрешить. |
| `npm ci` падает | Выполни `npm install`. Если ошибка про версию Node, вернись к шагу 2. |
| Тесты красные | Не запускай сайт молча: покажи пользователю, какие тесты упали, и разберись (читай `AGENTS.md`). |
| Сайт не открывается в браузере | Посмотри `start.log`, проверь `curl` из шага 5. |
| Нет прав на папку | Установи в другую папку внутри домашней, которую можно писать. |

## 8. Что сказать пользователю в конце (простыми словами, без терминов)

- Что установлено и где лежит (папка `trade_unit`), и как запускать в следующий раз (ярлык на рабочем столе).
- Сайт работает на этом компьютере и ничего не отправляет в интернет. Данные хранятся в браузере. Чтобы их не потерять,
  периодически нажимать «Сохранить в файл» (вверху справа).
- При первом запуске созданы две учётные записи: «Тест-пример» с готовыми данными (чтобы посмотреть, как всё работает) и «Пустая» для своих.
  Переключаются они в «Настройках» или списком вверху справа.
- Предложи пройти по вкладкам слева направо и объясни каждую простыми словами (порядок и смысл: README.md, раздел «Что умеет», и VISION.md).
- Пользователь может просить тебя объяснить, добавить или исправить что-то на сайте: ты это сделаешь, следуя `AGENTS.md`.

## 9. Обновление

В папке `trade_unit`: `git pull` (или скачай архив заново и перенеси папку `src`), затем `npm ci` и перезапусти сайт.
Данные пользователя в браузере при этом сохраняются.
